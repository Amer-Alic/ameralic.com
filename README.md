# ameralic.com

The source for Amer Alić's personal website. It is a static site built with plain HTML,
CSS, and a small amount of JavaScript.

## Deployment

The site is published by GitHub Pages from the root of the `main` branch. Every push to
`main` triggers a new deployment.

The custom domain is `ameralic.com`. DNS is managed through Cloudflare and points the
apex domain to GitHub Pages, with `www` configured as a redirecting alias.
